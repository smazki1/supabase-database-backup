# Rental Listings Tracker (Hebrew UI)

אפליקציה פשוטה למעקב אחרי דירות להשכרה:
- מדביקים קישור של מודעה.
- המערכת מנסה לחלץ נתונים מרכזיים (כותרת, מחיר, חדרים, שטח, מיקום, תיאור).
- המערכת שומרת את המידע ב-SQLite ומציגה גם תמונות שזוהו בעמוד.

## הרצה מקומית

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
streamlit run app.py
```

לאחר ההרצה פתחו את הכתובת שמודפסת בטרמינל (בד״כ http://localhost:8501).

## הערות חשובות

- חילוץ הנתונים מבוסס HTML ורג׳קס ולכן תלוי מאוד במבנה האתר.
- אתרים מסוימים חוסמים scraping או דורשים JS מתקדם.
- התמונות מזוהות מתגיות `img` בלבד.

## קבצים מרכזיים

- `app.py` – ממשק Streamlit + לוגיקת חילוץ ושמירה.
- `requirements.txt` – תלויות.
- `rentals.db` – בסיס הנתונים המקומי (נוצר אוטומטית בהרצה).
